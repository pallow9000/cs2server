# Site base — servidor CS2

Abra `index.html` no navegador.

## Arquivos

- `index.html` — estrutura e conteúdo do site.
- `style.css` — todo o visual.
- `script.js` — botão de copiar IP.

## O que alterar primeiro

1. Troque `PALLOW PLAYIT+` pelo nome do servidor.
2. Troque `pallow.playit.plus:1031` pelo IP.
3. Edite os comandos na seção "Comandos".
4. Edite os patches em "Atualizações".
5. Depois podemos adicionar logo, imagens, players online, regras, ranking, Discord e outras páginas.

O layout foi feito como uma base escura inspirada em páginas de comunidade/Steam, mas sem depender de framework.
